# QA preview images — review only

Everything under `public/qa-preview/lessons/**` is a **review aid for the P4.4
remediation queue**, not a publish-ready asset.

- Generated by extracting the source `.docx`'s own embedded preview image for
  each blocking `embeddedObject` (equation) issue, then converting it
  read-only from Windows Metafile (`.wmf`) to PNG. The two source `.docx`
  files were opened read-only; nothing in them was modified.
- Exact reproduction commands are in `docs/qa/tools/README.md` and
  `docs/handoffs/P4/P4.4-remediation-triage-claude.md`.
- Known limitation: the WMF renderer available in this environment
  (ImageMagick's `libwmf` delegate, with Inkscape as a fallback) does not
  always have the equation editor's original "Symbol" font available, so a
  Greek Δ ("delta") can render as a look-alike Latin glyph with an umlaut
  ("Ä"). Treat these images as a guide to an object's **type and rough
  content**, not a pixel-perfect rendering — the Owner should confirm exact
  symbols against the live object in Word when in doubt.
- A `previewPath` of `null` in the remediation queue means either the
  object's own embedded preview is genuinely empty in the source file
  (verified by rendering, not assumed — see the queue's
  `observedTypeEvidence` field for that item) or no preview relationship
  could be resolved; either way, the Owner must open the source `.docx`
  directly to inspect that specific object.
- These images must **never** be wired into a lesson's MDX as a `ChemFigure`
  fallback. A fallback image for publish requires the project owner's
  reviewed `remediationChoice: "reviewed-image-fallback"` decision in the
  matching `content/qa/pending/*.remediation-queue.json` entry, followed by a
  separate, deliberate task that adds it to the lesson content — this
  directory is not that task.
