## Objective

Build a no-application-login staging fixture for library/search metadata using the
approved Topic 6/8 `in_review` metadata. Demonstrate populated, loading, error and
empty states on desktop and mobile. This is not a personal or teacher dashboard.

## Required behavior

- Route stays outside the private/authenticated route group and is protected only by
  Vercel Preview Protection or Share Link. It must show a persistent
  “Staging — nội dung đang duyệt” banner and must not imitate the production
  `/thu-vien` or `/tim-kiem` routes.
- Source metadata from the canonical pilot manifest/content; do not duplicate or
  reinterpret chemistry content. Parse only the frozen frontmatter fields required
  for presentation: topic, title, slug, order, summary, keywords,
  `estimatedMinutes`, version and status. Fail visibly on malformed metadata.
- All lesson links target the existing `/fixtures/pilot/**` routes, never
  `/chuyen-de/**`. Cards show topic, title, summary, keywords, estimated time,
  `in_review` and current unresolved QA counts; no progress or publication claim.
  Derive current counts from `unresolved[]` in the final owner-signed QA record. Do
  not present the manifest's historical importer `blockingCount`/`warningCount` as a
  live count.
- Search runs on form submit. It performs case-insensitive and Vietnamese-diacritic-
  insensitive substring matching over title, summary, keywords and topic. Rank title
  matches first, then keywords, then summary/topic; ties use topic order then lesson
  order. Normalization removes Unicode combining marks and maps `đ`/`Đ` to `d`. This
  is a staging-fixture rule, not a production search contract.
- Empty query shows the two pilot topic suggestions. A non-empty zero-result query
  shows `Không tìm thấy kết quả cho “<query>”` plus a link back to the fixture
  library. An empty corpus is a distinct “Chưa có nội dung đang duyệt” state.
- Provide deterministic direct states via `?state=populated|loading|error|empty`.
  Loading retains page chrome and uses skeleton cards/rows, never a full-page spinner.
  Error retains the results region and exposes a keyboard-operable retry that returns
  to the populated state. No fake login/session is presented to the owner.
- Do not render an account menu, avatar, login prompt, teacher control, progress bar
  or personal state.
- Mobile width 375 px must not produce page-level horizontal overflow.
- Mark staging pages `noindex`; use exactly one `<main>`, labelled navigation and
  search landmarks, visible focus rings, and at least 44×44 px touch targets.
