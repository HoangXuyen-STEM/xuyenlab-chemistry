# P5.3 task — Codex integration and release rehearsal

## Start condition

Begin only after P5.1 and P5.2 have complete handoffs and green task-level checks.
Create `phase/p5-integration` from the approved integration baseline and merge/cherry-
pick task commits without rewriting their branches.

## Required reading

- all required repository instructions and P4 `SUMMARY.md`;
- all P5 coordination/task packets and P5.1/P5.2 handoffs;
- architecture, content, storage/environment and handoff contracts;
- changed workflow, generator, manifest, fixture UI and test files.

## Responsibilities

- Review contract/architecture consistency and unauthorized scope changes.
- Run repository verification, credential-free PDF/content dry-run and browser tests.
- Confirm PR workflows cannot upload and no production secret appears in output.
- Rehearse regeneration, backup and rollback on local/staging artifacts.
- Verify the no-login staging preview through Vercel protection/share link.
- Record external Neon Auth and real private signed-download checks as
  `DEFERRED TO P7`; do not attempt to solve them in P5.
- Write or update the backup/rollback runbook and create
  `docs/handoffs/P5/SUMMARY.md` with an explicit P5 exit verdict.

## Forbidden

- Publishing lessons or approving chemistry.
- Adding login/signup/account provisioning or authenticated dashboards.
- Production R2 upload without separate explicit project-owner authorization.
- Changing ADRs/contracts merely to make implementation agree.
