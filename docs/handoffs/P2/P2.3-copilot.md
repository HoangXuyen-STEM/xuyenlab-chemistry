## Decisions and assumptions

- Used JSON Schema draft-07 so the schema can be validated with the repo's current installed toolchain and no dependency-manifest changes.
- Modeled the regression corpus as normalized synthetic JSON inputs plus expected report JSON outputs because the Phase 2 converter entrypoint is not present yet.
- Bound fixtures to manifest-backed sources `T06-S01` and `T08-S01` so `sourceId` and `sourcePath` stay aligned with `docs/source-manifest.csv` and the frozen content contract.
- Treated idempotency for this task as stable report content for the same normalized input: same block IDs, locators, counts and `sourceDigest`, with only run metadata allowed to differ.
- Constrained fallback metadata by strategy:
  - `chemfigure` and `rasterized-inline` must carry real `assetPath` and `altText`;
  - `manual-review` must not require or emit fake asset metadata and may use a visible placeholder caption instead;
  - `datatable-html` does not require `altText` because it represents HTML table content rather than an image fallback.
- Bound real black-box coverage to `T06-S02`, whose manifest-backed HTML source
  has 26 list items and chemistry subscript notation needed to regress the
  defects found in P2.1 review.
- The black-box test creates and removes only its own `mkdtemp` directory under
  the operating-system temporary directory.
