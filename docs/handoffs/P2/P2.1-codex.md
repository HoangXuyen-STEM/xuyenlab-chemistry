## Decisions and assumptions

- Kept the HTML files as derivative fidelity references because the source manifest
  does not authorize them as canonical content.
- Kept strategy B (hybrid) as the provisional recommendation, not an approved
  decision. Strategy A is not feasible as the only v1 path at the measured OLE density;
  strategy C remains an exception fallback.
- Counted a visible warning placeholder as visible output while separately counting
  semantic failures, preventing the 95% visibility threshold from hiding fidelity loss.
- Used a deterministic prototype report epoch and source-derived run ID so identical
  reruns remain byte-for-byte stable. Production run auditing is outside this spike.
- Used `manual-review` for visible non-image placeholders. Integration review returned
  the initial P2.3 schema to Copilot because it incorrectly required fake image metadata
  for this strategy; the corrected strategy-conditional schema accepts all four real
  reports.
