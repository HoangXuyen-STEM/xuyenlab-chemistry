  remain review items; the importer does not infer correctness or alt text.

  input and was not silently promoted to canonical source.

  `approvedForPublish: false`. They are deliberately not valid owner-signed final QA

  and JSON pass the existing format gate. No dependency or lockfile change was needed.
- Local `public/staging-assets/` files are preview fixtures only; no R2 upload or cloud
  mutation occurs in P4.1.
