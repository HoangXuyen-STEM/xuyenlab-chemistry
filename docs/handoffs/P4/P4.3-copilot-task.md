# Task P4.3 — Copilot: content regression and staging E2E

## Assignment

Build independent regression coverage for the P4.1 Topic 6/8 drafts and P4.2 staging
presentation. Tests must not require Neon login. Use staging fixture URLs protected by
Vercel Preview Protection/Share Link for owner access, and local test seams for CI.

## Ownership

- Branch: `phase/p4-3-content-e2e` from the accepted P4.1 baseline; rebase onto P4.2
  only when testing final presentation.
- Allowed: `tests/**`, validator test fixtures, Playwright configuration/specs and
  `docs/handoffs/P4/P4.3-copilot.md`.
- Forbidden: production content wording, importer implementation, auth/DB/R2 adapters,
  UI implementation except a narrowly documented testability hook, production workflow,
  ADR/contracts, package/lockfile unless P4.1 explicitly delegates it.

## Definition of done

- Tests reject missing/invalid frontmatter, source mismatch, broken links/assets,
  duplicate identity and hidden blocking failures.
- Playwright covers Topic 6/8 staging load, mobile layout, headings/TOC, table overflow,
  visible fallback warnings and print-emulation smoke without app login.
- Accessibility smoke covers landmarks, heading order, keyboard controls and image alt.
- No test marks chemistry correct; owner QA remains the authority.
- Run full documented verification, write handoff, commit/push; do not merge.
