**Branch:** `p7.2-account-lifecycle`

## What shipped

| Item                       | Detail                                                                                                              |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Password sign-in allowlist | `signInWithPasswordAction` rejects emails not on allowlist / teacher list before calling Neon Auth                  |
| Sign-up allowlist (P7.1)   | Unchanged; still gates registration                                                                                 |
| Mark verified              | `markAllowedEmailVerified()` after successful password sign-in / sign-up, and on `requireUser()`                    |
| Google OAuth boundary      | Cannot pre-check email before IdP; **post-login** enforcement in `requireUser()` (sign-out + redirect with message) |
| Seed CLI                   | `npm run db:seed-allowlist -- --dry-run a@x.com` or `--file emails.txt`                                             |
| Login UX                   | `/dang-nhap?error=...` from revoke redirect is shown on the login form                                              |

## Owner how-to: seed allowlist

```bash
# Preview only (no DB write)
npm run db:seed-allowlist -- --dry-run hs1@school.edu hs2@school.edu

# From file (one email per line or CSV)
npm run db:seed-allowlist -- --dry-run --file ./data/class-emails.txt

# Real write (requires DATABASE_URL)
DATABASE_URL=... npm run db:seed-allowlist -- --file ./data/class-emails.txt
```

Teachers listed in `TEACHER_EMAILS` do **not** need to be in `allowed_students`.

## Security notes

- Revoking access: delete (or never insert) the student email from `allowed_students`. Next protected page load runs `requireUser()` → sign-out → `/dang-nhap?error=...`.
- Password sign-in is blocked at the form action if already revoked.
- Google OAuth users may complete the Google round-trip once; the first private page hits `requireUser()` and is signed out if not allowlisted.
