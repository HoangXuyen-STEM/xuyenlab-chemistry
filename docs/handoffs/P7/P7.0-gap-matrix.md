## Phân tích thực tế theo từng mảng (Verified Fact-based Audit)

### Mảng 1: Auth Integration (`@neondatabase/auth`)

- **Thư viện chính:** `@neondatabase/auth` (Neon Auth), **không dùng NextAuth**.
- **`src/lib/auth/neon.ts`**: Khởi tạo dynamic `createNeonAuth()` với `NEON_AUTH_BASE_URL` & `NEON_AUTH_COOKIE_SECRET`. (✅ Wired)
- **`src/lib/auth/server.ts`**: Cung cấp `getSession()`, `requireUser()`, `requireTeacher()` dựa trên Neon Auth session. Đã phân quyền `teacher` thông qua danh sách email trong `TEACHER_EMAILS`. (✅ Wired)
- **`src/lib/auth/actions.ts`**: Server Actions cho Email/Password (`signInWithPasswordAction`, `signUpWithPasswordAction`), Google OAuth (`signInWithGoogleAction`), Đăng xuất (`signOutAction`), và Quên/Đặt lại mật khẩu (`requestPasswordResetAction`, `resetPasswordAction`). (✅ Wired)
- **`src/app/api/auth/[...path]/route.ts`**: Proxy Handler nhận tất cả request auth từ trình duyệt (`sign-in`, `sign-out`, OAuth callbacks). (✅ Wired)
- **Giao diện Auth**:
  - `/dang-nhap` (`src/app/dang-nhap/page.tsx` + `LoginForm.tsx`) — ✅ Wired với Server Actions & Google OAuth.
  - `/quen-mat-khau` (`src/app/quen-mat-khau/page.tsx` + `PasswordResetRequestForm.tsx`) — ✅ Wired.
  - `/dat-lai-mat-khau` (`src/app/dat-lai-mat-khau/page.tsx` + `PasswordResetForm.tsx`) — ✅ Wired.

### Mảng 2: Navigation & Route Protection (`src/proxy.ts`)

- **Proxy chính:** `src/proxy.ts` (Next.js Proxy kế thừa từ Neon Auth SDK `neonAuthProxy`).
- **Matcher hiện tại:** `["/thu-vien/:path*", "/chuyen-de/:path*", "/tien-do/:path*", "/giao-vien/:path*"]`.
- **Trạng thái:** ✅ Wired cho việc điều hướng và làm tươi Session (Refresh session).
- **Lưu ý bảo mật (ADR-0003):** `src/proxy.ts` là lớp tiện ích giao diện (navigation convenience). Tất cả các route riêng tư và API route đều có bảo vệ Server-side độc lập qua `requireUser()` / `requireTeacher()`.

---

### Mảng 3: Database & Allowlist (`db/schema.ts` & `src/lib/db/`)

- **Lược đồ (Schema) hiện tại (`db/schema.ts`):**
  - `profiles`: `user_id` (PK), `display_name`, `role` (`student | teacher`), `joined_at`. (✅ In Schema)
  - `allowed_students`: `email` (PK), `invited_at`, `verified_at`. (✅ In Schema)
  - `lesson_progress`: `user_id`, `lesson_slug`, `status`, `read_percent`, `started_at`, `updated_at`, `completed_at`. (✅ In Schema)
  - `bookmarks`: `id`, `user_id`, `lesson_slug`, `anchor`, `label`, `created_at`. (✅ In Schema)
- **Repository (`src/lib/db/repositories.ts`):**
  - Đã hỗ trợ full CRUD cho `lessonProgress` và `bookmarks`. (✅ Wired)
  - **Gap:** Chưa có repository helper thao tác riêng cho `allowed_students` (ví dụ: `isEmailAllowed()`, `inviteStudent()`). (⚠️ Gap cho P7.2)

### Mảng 4: Private PDF Download (`src/app/api/pdf/[lessonSlug]/route.ts`)

- **Xác thực:** Endpoint `/api/pdf/[lessonSlug]` **ĐÃ CÓ** guard xác thực người dùng:
  ```ts
  await requireUser(); // Bắt buộc phải đăng nhập
  ```
- **Phân quyền bài học:** Hiện tại route sử dụng `getStagingPdfDownload(lessonSlug)` (`src/features/pdf/staging-pdf.ts`), giới hạn cho bài fixture staging (`p3-can-bang-hoa-hoc`).
- **Gap cho P7.3:**
  - Chưa nối bài thật với trạng thái `status === "published"` (hiện tại tất cả 26 bài học đang ở trạng thái `in_review`).
  - Cần tích hợp với Cloudflare R2 Private Bucket (`src/lib/r2/private-pdf.ts`) khi PDF thật được upload.
