### Exact security claim and test evidence

- **What is proven, unconditionally, on every platform:** the containment
  *check itself* (`resolveRepositoryFilePath`) runs on every file read in
  production, on every OS this app deploys to — it is plain Node.js
  (`fs.realpathSync`, `path.relative`), not conditionally compiled or
  feature-detected. A malicious symlink at a manifest-declared path would be
  rejected by this code path regardless of platform.
- **What is proven by a live regression, specifically on this session's
  Linux environment:** two new tests actually create a real symlink whose
  target resolves outside a disposable temp "repository root" and confirm
  `resolveRepositoryFilePath` throws — plus a paired control case proving an
  in-bounds symlink is still accepted (the check isn't "reject all
  symlinks"). Verified empirically, not just by the assertion passing, that
  the *old* lexical-only logic would have missed this: a throwaway script
  reproducing the old check's `path.relative` computation on the malicious
  symlink returned a clean in-bounds-looking relative path
  (`content/topics/chuyen-de-99/escape.mdx`), while `fs.realpathSync`
  correctly revealed the true target outside the root. Test run in this
  session: **both symlink tests executed (not skipped) and passed** on
  Linux.
- **What is honestly not claimed:** whether creating a plain-file symlink
  without elevated privilege succeeds is platform-dependent (Windows
  normally requires Developer Mode or an elevated process for file
  symlinks). The two symlink tests probe support once at test-file load
  time and use `it.skipIf(!symlinksSupported)`, so on a platform where the
  probe fails they report as skipped, not passed — this handoff does not
  claim the live symlink regression has been exercised anywhere it hasn't
  actually run. The lexical `../`-traversal test (unconditional, no
  filesystem symlink needed) and the unconditional production code path
  above are what back the security claim on such a platform, not a skipped
  test.
