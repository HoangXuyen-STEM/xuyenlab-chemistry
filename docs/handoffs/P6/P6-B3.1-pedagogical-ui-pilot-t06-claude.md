## Decisions and assumptions

- **Rule 4 ("broken reaction text → KaTeX with arrows") applied to 5
  places**, all missing-arrow general reaction schemes: `aA + bB C + dD`
  → `$$aA + bB \rightarrow cC + dD$$` (§3); `A Sản phẩm (4.1)` →
  `$$A \rightarrow \text{Sản phẩm}$$` + `(4.1)` (§4b, first-order);
  `2A Sản phẩm (4.4)` and `A + B Sản phẩm (4.5)` similarly (§4b,
  second-order case, 2 formulas); `CH3CHO CH4 + CO` →
  `$$\text{CH}_3\text{CHO} \rightarrow \text{CH}_4 + \text{CO}$$` (§4c).
  Style (plain letters + `\text{}` only for Vietnamese words, not
  `\mathrm{}`) matches the **real, already-Owner-approved precedent
  already living in this exact document** (`T06-S01:e4316`'s
  `$$aA + bB \rightarrow \text{Sản phẩm}$$`, applied in Batch A2)
  rather than the task's own illustrative `\mathrm{A}` example —
  internal consistency with real approved content took priority over a
  generic illustration. `H2 + Br2 → 2HBr` (§4b note) was **left as
  plain text** — it already has a real arrow character, so it isn't
  "broken," and converting it risked unnecessary scope creep.
  - **Self-correction caught before opening the PR**: the first draft
    left `A → Sản phẩm (4.1)` as plain Unicode-arrow text instead of
    real KaTeX, inconsistent with the other 4 fixes and with this
    handoff's own first draft (which already, correctly, described it
    as converted). Found by cross-checking every formula claim in this
    handoff against the real file with `grep` before finalizing, not
    caught by any automated test (no test asserts the _specific_
    fixed-arrow formulas' presence/absence, only that raw leakage is
    absent and the KaTeX count matches) — fixed, and the KaTeX-count
    assertion in `pilot-staging.spec.ts` updated from 24 to 25
    accordingly.
- **Garbled/ambiguous fragments were left completely untouched**, not
  "fixed": `Mol:3.10-31,5.10-3`, `t = 00,050,05`, `t0,05 – x0,05 -
x`, `v=kCA`, `CA = a - x`. These are OCR/extraction artifacts, not
  clearly "reaction text," and rule 6 forbids changing numbers or
  rewriting content — reinterpreting them would risk altering
  scientific content under the guise of "presentation."
- **Section 4's subsection labels ("a) Bậc phản ứng", "b) Một số loại
  phản ứng đơn giản", "• Phản ứng một chiều bậc nhất", "• Phản ứng một
  chiều bậc hai", "• Các loại phản ứng đơn giản khác", "c) Phản ứng
  phức tạp", "d) Thời gian bán hủy") are preserved byte-identical as
  plain paragraph text**, immediately before their content's Callout.
  The Callouts wrapping single-topic subsections (a, first-order,
  second-order, note, c, d) are **untitled** — the preceding label
  already serves as the heading, so a duplicate `title` would be
  redundant. Only two Callouts got an explicit `title`: section 3's
  (titled "Định luật tác dụng khối lượng" — informative, since section
  3 has no other preceding sub-label to lean on) and the two `Example`
  blocks (titled "Ví dụ 1"/"Ví dụ 2", per the task's own rule-3
  template).
- **"Thí dụ 1"/"Thí dụ 2" (inside "c) Phản ứng phức tạp") were NOT
