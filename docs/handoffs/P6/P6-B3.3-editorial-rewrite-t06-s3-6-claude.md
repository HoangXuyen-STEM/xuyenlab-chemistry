## Decisions and assumptions

- **Structure**: each major section got a short `<Callout
type="definition">` per new concept/reaction-type, `<Callout
type="note">` for memorable special cases, `<DataTable>` +
  `<Math formula="...">` cells for every symbol legend (≥3 symbols per
  the guide's own §5 rule), and `<Example title="Ví dụ N: ...">` +
  `<Solution>` for every worked problem — matching PR #59's real
  established pattern exactly (`### 4a.`/`### 4b.` sub-headings inside
  `## 4.`, matching the `### 2a.`/`### 2b.`/`### 2c.` convention
  already used in section 2).
- **Broken (missing-arrow) reaction schemes fixed into real KaTeX**:
  `aA + bB C + dD` → `$$aA + bB \rightarrow cC + dD$$` and similar for
  `A → Sản phẩm`, `2A → Sản phẩm`, `A + B → Sản phẩm`,
  `CH3CHO → CH4 + CO` — none of these carried a tracer comment in the
  original (they were narrative context, not Owner-approved OLE
  objects), so converting them to correct KaTeX is pure presentation,
  not a content change.
- **Two duplicate-original-text bugs caught and fixed before
  finalizing**: an early draft repeated the same equation both as
  inline `$...$` preview text and as the tracer'd `$$...$$` display
  formula immediately after (for `e3159` and `e9697`) — a real
  violation of the guide's own "không lặp ý" (no repeating the same
  idea) rule that I introduced myself. Caught by rereading the
  rendered output, not by any automated check; fixed by removing the
  redundant inline preview in both places.
- **One placement bug caught via automated verification, not
  eyeballing**: an early draft used my own inline `$aA + bB \rightarrow
\text{Sản phẩm}$` prose instead of the real `e4316` tracer block in
  §4a, silently dropping that tracer. Caught by a scripted check
  (`grep`-diffing every `B['id']` key used against the full extracted
  set) that surfaced 4 missing tracers (`e4316`, `e0189`, `e0742`,
  `e6260`) before the file was even written to disk — see "Traceability
  gaps found and fixed" below.
- **Traceability gaps found and fixed** (rule 8 of the style guide:
  "quan trọng hơn cả tính súc tích" — traceability outranks
  conciseness):
  - `e4316` (general reaction scheme, §4a) — restored to its own line
    with the tracer, instead of being silently folded into prose.
  - `e0189` (§6b, Ví dụ 1) — this formula is byte-identical to
    `e3265`/`e3603` (already shown in §4b). Added it explicitly in Ví
    dụ 1's problem statement with an inline `{/* same as e3265
above */}` comment, per the guide's own exact suggested pattern
    for genuinely duplicate formulas — not silently omitted.
  - `e0742`, `e6260` (§6b, Ví dụ 2) — the original document shows these
    inside the problem statement itself ("Tính: a) ... {e0742} b) ...")
    before "Giải" formally begins, an odd but real feature of the
    source text. Preserved both, in their same logical position within
    the worked solution, rather than omitting them as "redundant" with
    the later `e9792`/`e9097` formulas that partially overlap them.
  - `e5276` (§6b, Ví dụ 3, final line) — numerically identical to
    `e4186` just above it (same value, `≈216,5 phút`). This is the one
    _genuinely_ duplicate formula in the whole span; per rule 8, kept
    it with an inline `{/* same as e4186 above */}` comment rather than
    deleting it.
- **Ví dụ 1 in §6b's problem statement was reconstructed**, not
  literally transcribed: the original intro ("Hòa tan 10-2 mol NaOH
  vào 10-2mol vào 1 x1,107 lít H2O ở 27oC.") is OCR-corrupted and
  doesn't parse chemically. Rebuilt the problem statement using **only
  facts recoverable from the untouched solution formulas themselves**
  (bậc 2, ethyl acetate saponification via `e0189`, 3/4 decomposed in
  2h, 27°C→127°C with a 4× rate increase — all directly visible in the

  Deliberately **omitted** the initial concentration value "a" from
  the reconstructed problem text, since the true numeric value never
  survives anywhere in the source (the solution only ever uses "a"
  symbolically, e.g. `e8721`'s `k = 3/(2a)`) — not inventing a number
  that isn't recoverable.
- **Ví dụ 2's intro gap-filled the same way**: "tiến hành ở," and "Ở
  nồng độ giảm..." (missing the T1/T2 placeholders) were completed
  using the tracer'd `e8081`/`e8680` values (T1=25°C, T2=40°C) that
  immediately follow in the original — not invented, just moved the
  already-present values into the sentence that clearly needed them.
- **§6b Ví dụ 3's dense titration derivation** (28 tracers) required
