## Decisions and assumptions

- `package-lock.json` is the only package-manager lockfile; P1.2 must use `npm ci`.
- Node 22 is the reproducible CI/Vercel target. Local verification used Node 24.18.1,
  which is inside the declared supported range.
- TypeScript is pinned to 5.9.3. Newer TypeScript 6/7 releases were not retained
  because the installed Next.js/type-aware ESLint combination did not complete all
  required checks reliably.
- ESLint is pinned to major 9 because `eslint-config-next` 16.3 transitive plugins do
  not yet declare ESLint 10 compatibility.
- Cloud variables remain optional during P1 so local and preview fixture builds need
  no secrets. Each adapter task must make its own required variables mandatory when
  that integration is activated.
- Tailwind CSS is intentionally not part of the shared foundation. P1.3 may specify
  design tokens in docs; a later bounded implementation can choose the styling layer
  without coupling the app bootstrap to a premature design decision.
