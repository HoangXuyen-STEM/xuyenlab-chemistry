## Decisions and assumptions

- P3 uses an exact staging-only fixture allowlist because no canonical published lesson
  exists. It is not a substitute for the P4 published-content authorization check.
- The signer reads R2 credentials only on the server at call time and does not log a
  signed URL or credential value.
- R2 uses an account endpoint with SDK region `auto`, per Cloudflare’s current S3 API
  documentation.
